# Custom Hangman Game

A classic, text-based Hangman game developed in Python, where the player guesses a hidden word one letter at a time within a limited number of attempts.

## Features

- **Well-Structured:** Game logic is clearly organized to handle user input, validation, and win/loss conditions.
- **Robust Input Handling:** Includes validation to ensure the player enters only valid single alphabetic characters.
- **Interactive:** Provides real-time feedback on correct guesses, remaining attempts, and prevents duplicate letter guesses.
- **Clearly Reported:** Game state is displayed in a user-friendly format after every turn.

## Technologies Used

- Python 3.x
- Built-in Modules: `random`

## Installation & Setup (Reproducible)

### 1. Prerequisites
Make sure Python is installed on your system. No external libraries are required.

### 2. Running the Application
Simply run the script using your terminal or IDE:

```bash
python hangman.py
```

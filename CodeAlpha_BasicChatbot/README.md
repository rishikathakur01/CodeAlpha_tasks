# Basic Chatbot

Basic Chatbot focuses on providing interactive, rule-based responses to user inputs.

## Features

- **Well-Structured:** Logic is neatly organized into reusable functions for maintainability.
- **Interactive:** Provides a seamless loop-based conversation flow until the user chooses to exit.
- **Robust Input Handling:** Automatically standardizes user input to ensure case-insensitive matching.
- **Clear Logic:** Utilizes fundamental programming structures for predictable and consistent responses.

## Technologies Used

- Python 3.x

## Installation & Setup (Reproducible)

### 1. Prerequisites
Make sure Python is installed on your system. No external libraries are required.

### 2. Running the Application
Simply run the script using your terminal or IDE:

```bash
python chatbox.py
```

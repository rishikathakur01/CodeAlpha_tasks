# Stock Portfolio Tracker

A simple Python application that allows users to track their stock investments by calculating the total value based on predefined stock prices.

## Features

- **Well-Structured:** Uses a dictionary to manage predefined stock prices for efficient lookup.
- **Interactive:** Allows users to dynamically input stock symbols and quantities until they choose to exit.
- **Calculation Logic:** Automatically performs arithmetic calculations to track total investment value.
- **Data Persistence:** Provides an optional feature to save the final portfolio summary into a `.txt` file.

## Technologies Used

- Python 3.x
- Built-in Modules: File handling operations

## Installation & Setup (Reproducible)

### 1. Prerequisites
Make sure Python is installed on your system. No external libraries are required.

### 2. Running the Application
Simply run the script using your terminal or IDE:

```bash
python tracker.py
```
